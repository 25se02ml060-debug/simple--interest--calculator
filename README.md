# Simple Interest Calculator

## Description

The Simple Interest Calculator is a basic calculator used to calculate the simple interest and total amount based on the principal amount, rate of interest, and time period.

## Formula

**Simple Interest (SI):**

SI = (P × R × T) / 100

Where:

* **P** = Principal Amount
* **R** = Rate of Interest per year
* **T** = Time Period in years

**Total Amount:**

Amount = P + SI

## Example

Suppose:

* Principal = ₹10,000
* Rate = 5% per year
* Time = 2 years

Simple Interest:

SI = (10000 × 5 × 2) / 100

SI = ₹1,000

Total Amount:

Amount = 10000 + 1000

Amount = ₹11,000

## Features

* Easy to understand
* Calculates simple interest
* Calculates total amount
* Suitable for basic financial calculations

## Conclusion

The Simple Interest Calculator provides a simple way to calculate interest and the final amount using the principal, rate, and time values.
